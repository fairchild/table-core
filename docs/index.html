@fairchild/table-core

Loads table rows from a server one page at a time and keeps the count right, with helpers for a selection. It is the part of Lede's data table that doesn't depend on React or the DOM, so you can use it from any framework or from Node.

It has no columns, no rendering and no virtualization. You render the rows yourself, or use Lede's DataTable, which is built on the same store. 

npm install @fairchild/table-core

Is it for you?

Use it when

  • your rows live on a server and come a page at a time;
  • you render the table yourself, or with Lede's DataTable;
  • you want a correct count, cancellation and failures without writing them.

Use something else when

  • you want columns, cell rendering or virtualization: it has none. Try TanStack Table or a grid;
  • all your rows are already in memory: sort them yourself;
  • you want a general data cache for your whole app.

Tests

The tests answer each request by hand and control the clock, so they check the exact order of events without a browser or timers. The guide lists what they cover.

  • An outdated request is aborted, and a late reply to it is ignored.
  • Rows added or removed on the server between visits show up, and the count follows.
  • A late count doesn't replace a newer total.
  • If a refresh fails, the old rows and their count stay on screen, marked with their age.
  • Deleting rows from a “select all” selection keeps the count correct.
  • The package has no dependencies and imports only its own files.

What it does

  • Fetches pages

    Calls your function for each page, by offset or by cursor. With “Load more” it keeps adding pages; in pages mode it shows one page at a time.

  • Caches and cancels

    Keeps pages per view, so switching back is instant. Aborts requests you no longer need and merges duplicate ones.

  • Keeps the count right

    Reports a total of “at least 100” until your count endpoint answers, so you can show “50 of 100+”, then the exact number. Asks again when the rows are refreshed.

  • Reports its state

    Tells you whose rows are on screen, whether more are loading, what failed and how old the rows are, so you can render each case.

  • Helps with selection

    Pure functions over a selection you hold: a list of ids, or “all matching, except these”. They count it and drop rows deleted on the server.

  • Has no dependencies

    Plain TypeScript. Subscribe to changes and read a snapshot; Lede's React hook is a few lines on top.
